# Manufacturing Inference Advisor Constitution

## Core principles

1. Requirements and evidence precede recommendations. Unknown values remain unknown.
2. Deterministic, versioned calculations are separate from agent narrative and expose formulas, inputs, assumptions and confidence.
3. Hardware-neutral specifications precede candidate products and BOM approval.
4. Brand location never proves manufacturing origin. Regulated sourcing requires authoritative evidence and qualified human approval.
5. Requirements, architecture, specifications, BOM lines, screening and deployment remain traceable and reproducible.
6. Containers run with least privilege; credentials and confidential project data are never committed or emitted in logs.

## Delivery gates

Spec Kit artifacts and AEE assessment precede implementation. Unit, contract, compliance, MCP transport and container tests must pass. CMMC, ITAR and export-control profiles are workflow controls rather than certifications. Performance claims require workload-specific benchmarks.

## Governance

This constitution controls project-local design. Amendments require rationale, affected artifacts and migration steps. The project uses Spec Kit 1.0.6, community AEE 1.0.0, community Evaluator 1.0.0 and AEE engine 1.0.2 as recorded in `spec-kit-extensions.lock.json`.
