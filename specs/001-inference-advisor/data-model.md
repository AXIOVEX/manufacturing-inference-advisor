# Data model

`ProjectRequest` contains models, concurrency, workloads, availability, compliance, infrastructure, site constraints, sensitivity and growth. `Component` carries specification, quantity, candidate identity, origin/assembly, evidence, supplier, price, availability, firmware/software review and status. `SourcingPolicy` carries project-specific origin, prohibited-country and review requirements. Every output carries `inference-advisor/v1`; persisted artifact sets are content-addressed.
