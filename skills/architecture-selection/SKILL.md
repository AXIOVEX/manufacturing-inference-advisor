# Architecture selection
Use after requirements analysis. Call `assess_existing_infrastructure_tool` when an inventory exists, then `recommend_architecture_tool`. Compare existing integration, a separate server, a new secured platform and hybrid deployment. Preserve capacity assessment and classification. Validate interfaces, trust boundaries, availability, growth and operations maturity. If evidence is insufficient, return multiple options; never invent site capacity. Controlled-data and production architecture require human security review. Output alternatives, reasoning, migration, rollback, risks and assumptions.
