# Verification

Use before calling a design implementation-ready. Re-run `validate_requirements_tool`; compare requirements to architecture, specification, BOM screening and deployment plan. Use `save_project_artifacts` only when persistence is requested. Verify hashes, schema versions, formulas, gaps, tests and approvals. Tool success does not prove performance, truth or compliance. Fail on disagreement or absent evidence and prescribe bounded recovery. Human reviewers close regulated/production gates. Output traceability, status, gaps and recovery.
