# Existing Infrastructure Integration

Use when inventory, topology, storage, identity, observability, rack, power or cooling facts are supplied. Call `assess_existing_infrastructure_tool`, then architecture selection. Preserve inventory date/source. Validate capacity, compatibility, segmentation, data flow, failure domains and ownership. Missing inventory is unavailable evidence, not reusable capacity. Never connect controlled inference directly to OT networks without a reviewed boundary. Infrastructure/security owners approve integration. Output reuse, incompatibilities, gaps, changes and decision.
